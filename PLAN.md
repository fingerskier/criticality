Self-Organizing Critical System Simulator
----
Visualize a reactangle where each pixel is an item.
Items have a health score from 0-1.
Pixel color indicates health.
If an item is pathological then it has a probability of triggering (or increasing) the pathology of its neighbors.
There is a probability that an external event can trigger a pathology in a random item.
Give a panel with sliders/inputs to adjust system parameters.
